# Software Scope Checklist

Use this checklist before starting website/software development.

## Business & Goal
- [ ] Primary business goal is clear
- [ ] Target users are defined
- [ ] Success metric for first 90 days is defined

## Feature Scope
- [ ] Must-have features are listed
- [ ] Nice-to-have features are separated
- [ ] Out-of-scope list is documented

## Technical
- [ ] Preferred stack is selected
- [ ] API and integration needs are documented
- [ ] Hosting, domain, and SSL are prepared

## UI/UX
- [ ] Core pages are mapped
- [ ] Mobile behavior is specified
- [ ] Conversion CTA is defined on each page

## Delivery
- [ ] Timeline and milestones are approved
- [ ] UAT owner is assigned
- [ ] Go-live checklist is prepared
